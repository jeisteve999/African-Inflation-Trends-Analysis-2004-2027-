# African-Inflation-Trends-Analysis-2004-2027-
Analysis of African inflation trends using IMF data from 2004–2027. The project explores inflation volatility, country-level performance, temporal trends, and macroeconomic stability through Python-based data analysis and visualization.

# Project Overview

This project explores inflation patterns across African countries using IMF inflation data from 2004 to 2027.

The objective is to identify countries with persistent inflationary pressures, measure inflation volatility, analyze historical trends, and highlight notable case studies such as Zimbabwe.

# Dataset

Source: International Monetary Fund (IMF)

The dataset contains annual inflation rates for African countries and regional economic groups between 2004 and 2027.

# Key Questions
- Which African countries experienced the highest average inflation?
- Which countries showed the greatest inflation volatility?
- How has inflation evolved over time?
- What can Zimbabwe's inflation history tell us about economic instability?
# Main Findings

-Zimbabwe recorded the highest average inflation rate in the dataset (117.9%).
-South Sudan ranked second with an average inflation rate of 68.8%.
-Inflation volatility was highest in Zimbabwe (221.5), followed by South Sudan (91.8).
-Average inflation across the dataset peaked in 2024 at 23.6%.
-Most African countries maintained inflation levels below 20%, although several experienced severe inflationary shocks.

# Conclusions

The analysis highlights significant differences in inflation performance across African countries. Understanding these patterns is essential for evaluating economic stability and informing policy decisions.
